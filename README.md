# Taller 1 - Trabajo colaborativo con Git y GitHub

Proyecto de clon inicial de la landing page de MercadoLibre, realizado como ejercicio de trabajo colaborativo para el curso de Ingeniería de Software.

## Tecnologías

- HTML
- CSS
- JavaScript
- Git y GitHub

## Estructura de ramas (GitFlow simplificado)

- `develop`: rama principal de desarrollo.
- `feature/dev-portfolio-1`: portafolio del desarrollador 1 (Juan Manuel).
- `feature/dev-portfolio-2`: portafolio del desarrollador 2.
- `feature/dev-portfolio-3`: portafolio del desarrollador 3.
- `feature/dev-portfolio-4`: portafolio del desarrollador 4.

Cada desarrollador debe:

1. Crear su rama desde `develop`:

   ```bash
   git checkout develop
   git pull
   git checkout -b feature/dev-portfolio-X
